在 CoreS3 上怎么实现

  1. UI 框架用 LVGL：渐变背景、圆角卡片、阴影、半透明、动画都是 LVGL 自带的能力，这套界面基本能 1:1 做出来。
  2. 机器人用图片：每个表情先导出成带透明通道的 PNG（约 120px），放进 Flash 或 SD 卡；眨眼、说话用几帧图片轮换。
  3. 背景渐变：用 LVGL 的 bg_grad 实时画，或者直接用一张 320×240 的背景图。
  4. 少用模糊：这一版已经去掉了毛玻璃效果，卡片改成白色半透明，ESP32-S3 能流畅渲染。
  5. 中文字体：用 LVGL 字体转换工具只导出用到的汉字（12/14/18px），体积可以控制在几百 KB。
